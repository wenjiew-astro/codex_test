## Fireworks Visualization

This repository includes `fireworks.py`, a small Pygame program that renders animated fireworks.

### Requirements
- Python 3.11 or newer
- [Pygame](https://www.pygame.org/)

Install Pygame (if not already installed):

```bash
pip install pygame
```

### Running

Execute the script using Python:

```bash
python fireworks.py
```

Press `SPACE` to launch a random firework or click the window to launch one at that horizontal position.
